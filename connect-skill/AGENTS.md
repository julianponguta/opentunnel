# OpenTunnel Connect

Use this skill when user wants to connect to a remote server via SSH.

## Quick Start

1. Ask: "¿Cuántos minutos? ¿Qué usuario?"
2. Start webhook server with `node server.js`
3. Provide command to user
4. Wait for credentials
5. Connect via ezssh

## Commands

```bash
# Install dependencies
npm install

# Start webhook server
node server.js
```

## Dependencies

- Node.js
- express (npm)
- bore CLI
